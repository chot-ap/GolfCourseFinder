# GolfCourseFinder ⛳

楽天GORAプラン検索APIを活用し、笹塚からの電車所要時間、神田からの車所要時間、クラブバス送迎有無を自動計算して最適なゴルフ場を効率的に探せるHTMLベースのWebアプリケーションです。

---

## 🌟 主な機能と特徴

1. **楽天GORAプラン検索API連携**
   - プレー日、エリア（関東・甲信越・東海等）、都道府県、スタート時間帯（早朝、8時台、9時台、10時台等）を指定してリアルタイム検索。
   - 楽天Application IDを設定することで、最新の空き枠プランと料金を取得可能。
   - APIキー未設定時でも動作する高精度な**デモ/サンプルモード**を内蔵。

2. **出力条件（自動フィルタリング）**
   - **GORAレート3.5以上**のゴルフ場のみを抽出。
   - ゴルフ場名称に「**アコーディア**」が含まれている場合は**完全除外**。

3. **移動所要時間＆クラブバス自動算出**
   - 🚆 **笹塚からの電車の所要時間**: 京王線笹塚駅を出発地とし、新宿/東京/上野/池袋等を経由した最寄り駅までの鉄道時間＋バス/タクシー時間を自動計算。
   - 🚗 **神田からの車での所要時間**: 千代田区神田（首都高神田橋・本町周辺）を出発地とし、各高速道路（東関道、館山道、アクアライン、常磐道、東北道、関越道、中央道、東名等）＋最寄ICからの一般道時間を高精度に算出。
   - 🚌 **クラブバス送迎有無**: 送迎バスの有無、運行駅名、予約要否（「あり（〇〇駅発）」「要予約」「なし」等）を判定してバッジ表示。

4. **指定出力フォーマットへの一括エクスポート**
   - 以下の形式で一括テキストコピー＆CSVダウンロードが可能：
     ```text
     日付|ゴルフ場名|笹塚からの電車の所要時間|クラブバス送迎有無|神田からの車での所要時間|
     ```

5. **リゾート感あふれるモダンUI**
   - エメラルドグリーンとスレートダークを基調としたグラスモフィズムデザイン。
   - 各種カラムでのソート（電車時間順、車時間順、評価順、料金順）に対応。
   - コース詳細モーダルでプラン詳細・スタート時間・GORA公式予約リンクを確認可能。

## 🚀 起動方法

### 方法1: ローカルサーバー起動（推奨 / CORS対応）
Python 3 がインストールされている環境で以下のコマンドを実行します：

```bash
python server.py
```

ブラウザで `http://localhost:8000` を開きます。

### 方法2: ブラウザで直接開く
`index.html` をブラウザ（Chrome / Edge 等）でダブルクリックして開くだけでも、デモモードおよび各種機能をご利用いただけます。

---

## ⚙️ 楽天Application ID（APIキー）の設定方法

1. 画面右上の「⚙️ 設定 (API Key)」ボタンをクリックします。
2. [Rakuten Developers](https://rakuten-api-documentation.appspot.com/) で取得したご自身の **Application ID** を入力して「設定を保存」をクリックします。
3. これにより、楽天GORAのライブAPIからリアルタイムにゴルフ場・空き枠情報を取得するようになります。
